# Asset contract — "Special Military Operation" (working title)

Browser RTS (Three.js r187, WebGL2). All assets are authored procedurally in Blender (`bpy` 5.2 Python module,
headless) by scripts committed under `tools/blender/`, so every asset can be regenerated. Output is glTF binary.

## Global conventions
- Units: metres. glTF Y-up. **Model forward = +Z**, right = −X (three.js default facing). Origin on the ground at the footprint centre.
- Materials: glTF PBR metallic-roughness only. Name materials meaningfully (`emr_camo`, `steel_paint_green`, `track`, `glass_broken`...).
- Textures: generated by our own scripts (numpy / Blender bakes), embedded in GLB, JPEG for colour, PNG for normal/ORM.
  Max 2048², prefer 1024². Keep each GLB under ~15 MB.
- Licences: only self-made content, MakeHuman data (CC0), CMU mocap (free for any use). No downloaded third-party models/textures.
- Each asset gets a preview: `node tools/preview.mjs <glb> previews/<name>.png "views=4"` (headless Chromium, three.js, same renderer as the game). Inspect the PNG with the Read tool and iterate until it looks right.
- Performance budget (LOD0): soldier ≤ 25k tris all-in, vehicle ≤ 90k, building kit piece ≤ 3k, prop ≤ 8k. Provide `<node>_LOD1` meshes (~25–30% tris) for soldiers and vehicles.
- Machine has 2 CPU cores shared by several workers: run Blender with `nice -n 10`, avoid Cycles renders/bakes above 64 samples.

## Soldiers — `assets/soldiers/`
- Base: MakeHuman base mesh + macro targets from `/home/claude/mpfb2/src/mpfb/data/` (base.obj, targets, `rigs/standard/rig.cmu_mb.json` + `weights.cmu_mb.json`). Rig = **cmu_mb** skeleton so CMU BVH plays without retargeting.
- `soldier_ru.glb`, `soldier_ua.glb`: one shared skeleton, several body/head variants as separate SkinnedMesh nodes (`body_A`, `body_B`, `body_C`), plus gear nodes toggled by the game: `helmet_A/B`, `vest`, `pouches_*`, `backpack`, `armband_L`, `armband_R`, `legband_R`, `hands`.
  - RU: Ratnik EMR ("tsifra") uniform, **6B46** lightweight plate carrier w/ 6Sh117-style pouches, 6B47 helmet w/ cover, **white** tape armbands (alt material `tape_red`).
  - UA: MM-14 pixel uniform (some multicam tops), plate carrier (JPC-style) in multicam/coyote, MICH/FAST-style helmet w/ cover, **yellow** tape armbands.
- Weapons (separate GLBs, origin at pistol grip, +Z = muzzle direction, empties `muzzle`, `grip_R`, `grip_L` (support hand)): `ak74m.glb`, `pkm.glb`, `rpg7.glb`.
- Bone names: the cmu_mb names. Document the right/left hand bone names in `assets/soldiers/manifest.json`.
- Animations: `soldier_anims.glb` (skeleton + clips only) shared by both factions. Required clips (in place, root motion stripped, loopable where noted, 30 fps):
  `idle_rifle`(loop) `walk_rifle`(loop) `run_rifle`(loop) `crouch_idle`(loop) `crouch_walk`(loop) `prone_idle`(loop) `prone_crawl`(loop)
  `aim_stand`(loop) `aim_crouch`(loop) `aim_prone`(loop) `fire_stand` `reload_stand` `reload_crouch` `throw_grenade` `hit_react`
  `death_front` `death_back` `death_crumple` `wounded_ground`(loop) `wounded_crawl`(loop) `limp_walk`(loop) `drag_wounded`(loop) `suppressed_cower`(loop)
  Manifest lists each clip's duration, loop flag, and walk/run/crawl ground speed (m/s) so the game can sync foot speed.

## Vehicles — `assets/vehicles/`
- `btr82a.glb` (RU, BPPU turret with 30 mm 2A72 + PKTM), `btr80_ua.glb` (UA, BPU-1 turret with KPVT 14.5 mm + PKT), `t72b3.glb` (RU, Kontakt-5/Relikt ERA, cope cage), `t72av_ua.glb` (UA, Kontakt-1 ERA bricks).
- Hierarchy: `root > hull > turret > gun_pivot (at trunnion, rotates about X) > muzzle (empty)`; coax `coax_muzzle`; wheels `wheel_L1..L4`, `wheel_R1..R4` (BTR, pivot at hub); tanks: `roadwheel_L1..6`, `sprocket_L/R`, `idler_L/R`, and track meshes `track_L`/`track_R` using material `track` (UVs laid along the track so the game scrolls U to animate).
- Empties: `exhaust`, `dismount_L`, `dismount_R` (BTR side doors), `commander_hatch`, `smoke_launchers`.
- Damage variants inside the same GLB, hidden by default: `hull_wreck`, `turret_wreck` (burnt, separate so T-72 turrets can be blown off).
- `manifest.json`: dimensions, crew/passenger capacity, node list.

## Environment — `assets/env/`
Buildings are a **modular kit** assembled by the game (Soviet large-panel construction = literally prefab panels, so this is both authentic and what enables dynamic destruction):
- `panel_kit.glb`: exterior wall panels on a 3.2 m × 2.8 m module (series 1-464 / 1-468 style), each with damage states
  `_intact`, `_damaged` (scorch, cracks, broken glass), `_holed` (shell penetration, exposed rebar), `_destroyed` (stub with rebar):
  `wall_window`, `wall_balcony`, `wall_blank_end`, `wall_entrance`, plus `slab_floor`, `slab_floor_broken`, `roof_parapet`, `balcony_slab`, `balcony_hanging`, `stair_core`, `plinth`, `entrance_canopy`, interior partition walls and some furniture debris. Pivot at bottom-left-outer corner, panel lies in XY plane, outside face = +Z.
- `rubble_*.glb` (several piles + loose slabs with rebar + brick scatter), `trees.glb` (shrapnel-stripped poplar/chestnut, broken trunks, a couple leafy, stumps), `wires.glb` (Soviet concrete utility poles, trolleybus poles, concertina coil, barbed-wire fence segment), `props.glb` (burnt Soviet sedan, burnt bus, Czech hedgehogs, sandbag walls, tyres, garage row segment, bus stop, playground frame, kiosk).
- Tiling textures `assets/textures/`: asphalt (cracked), concrete panel, silicate brick, dirt/mud, rubble ground, each `_albedo.jpg`, `_normal.png`, `_orm.png` (2048² seamless).
- `manifest.json`: every node name, its bounding box, and kit module dimensions.
